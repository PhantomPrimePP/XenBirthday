Birthday photos and art go here. Your existing WelcomePage and TeasePage pictures are used by the app.

Add the six art files to `Arts/`, then set each matching `artImage` in `src/app/birthday-content.ts` to a path such as `/images/Arts/sylus.png`. Add the quote and artist name to `artistQuote` and `artistCredit` for that entry. For the mole game, add the target image and set `media.moleImage`.
